How Earlier Assigned Job Upload Works

This page is a standalone portal specifically designed for re-uploading or pasting previously assigned jobs that are yet to be finished.

  • Automatic Username & IP Extraction: The system automatically extracts the Allocated User (username) and Station IP columns from your CSV/paste.
  • Automatic User Dashboard Re-Linking: The active jobs are automatically linked to the user's account and instantly appear under their "My Active Allocated Work" tab.
  • Username Re-Use Support: If a user re-registered after a website update, their username is automatically matched to their new active account.
  • Admin Manual Fallback: If any uploaded record cannot find a matching username, you can easily assign it to any user from the Session Tables page with 1 click.
